# 분기점 기록

**"어떻게 여기까지 왔는가"** 를 남기는 곳입니다.

작업 덩어리(대략 주차 단위) 하나가 끝날 때마다 파일 하나를 만듭니다.
계획서(`../plan.md`)가 **앞으로 할 일**이라면, 여기는 **실제로 있었던 일**입니다. 둘은 자주 다릅니다. 그 차이가 이 폴더의 존재 이유입니다.

## 규칙

- 파일명은 `NN-영문슬러그.md`, 내용은 한국어
- **잘 안 된 것을 빼지 않습니다.** 막혔던 것과 어떻게 풀었는지가 가장 쓸모 있는 기록입니다
- 한 번 쓴 기록은 고치지 않습니다. 나중에 생각이 바뀌면 다음 기록에 씁니다
- `/milestone` 명령으로 작성합니다

## 예정된 분기점

| 파일 | 시점 | 내용 |
|---|---|---|
| `00-setup.md` | Day 1 | 계획 수립과 문서·자동화 세팅 |
| `01-skeleton.md` | Day 4 합격 | 뼈대와 배포 루프 |
| `02-voice.md` | Day 8 합격 | 말하기와 듣기 |
| `03-tutor.md` | Day 12 합격 | 튜터링과 상황극 |
| `04-avatar.md` | Day 16 합격 | 아바타와 마무리 |
